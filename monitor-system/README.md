# Система управления агентами майнера (Monitor)

## Описание
Система для управления агентами майнера (Monitor) через веб-панель. Позволяет управлять несколькими агентами, установленными на удалённых ПК, управлять процессами Monitor, собирать статистику и отправлять команды с веб-панели.

## Архитектура

### Компоненты
- **Сервер** (Go): Принимает HTTP-запросы от агентов и веб-панели, управляет очередью команд, поддерживает WebSocket-соединения с агентами, управляет Proxy.
- **Агент** (Go): Работает на ПК с Monitor, отправляет статистику на сервер, получает команды по WebSocket, управляет процессом Monitor.

## Установка и запуск

### Сервер
1. Установите зависимости:
```bash
cd server
go mod tidy
```

2. Настройте конфигурацию в `configs/config.yaml`

3. Запустите сервер:
```bash
go run cmd/server/main.go
```

### Агент
1. Установите зависимости:
```bash
cd agent
go mod tidy
```

2. Настройте конфигурацию в `configs/agent-config.yaml`

3. Запустите агента:
```bash
go run cmd/agent/main.go
```

## API

### Маршруты сервера
- `GET /api/v1/agents` – получить список агентов
- `GET /api/v1/agent/{id}` – получить конкретного агента
- `POST /api/v1/agent/{id}/command` – отправить команду агенту
- `GET /api/v1/commands/queue` – получить очередь команд
- `GET /api/v1/download/monitor/{platform}` – скачать Monitor (агентом)
- `POST /api/v1/proxy/start` – запустить Proxy
- `POST /api/v1/proxy/stop` – остановить Proxy
- `GET /api/v1/proxy/status` – получить статус Proxy

### Команды агента
- `start_monitor` – запустить Monitor
- `stop_monitor` – остановить Monitor
- `restart_monitor` – перезапустить Monitor
- `update_config` – обновить конфигурацию Monitor

## Безопасность
- Все соединения аутентифицируются по токенам
- Поддержка HTTPS/WSS
- Защита от несанкционированного доступа

## Поддерживаемые платформы
- Windows
- Linux

## Конфигурация
Сервер и агент используют YAML-файлы конфигурации для настройки параметров подключения, токенов и путей к бинарным файлам.
